# AI 모델 테스트 인사이트

## 테스트 환경
- **서비스**: OpenGateway (OpenAI-compatible API)
- **용도**: 만다라트 하위 목표 실천 계획 생성
- **평가 기준**: 구체성, 실행 가능성, 시간/횟수 포함 여부

---

## 모델별 비교

### 테스트 1: "n잡" 하위 목표 실천 계획 생성

| 모델 | 평가 | 특징 |
|------|------|------|
| **Claude 3 Haiku** | ⭐⭐⭐⭐⭐ | 구체적 시간("주 1회", "퇴근 후 1시간"), 플랫폼명("인프런/Udemy"), 실행 가능한 액션 |
| **Claude 3.7 Sonnet** | ⭐⭐ | 너무 추상적, 입력값("n잡")이 그대로 출력됨, 목표지 계획이 아님 |
| **Claude 3.5 Haiku** | ⭐⭐⭐ | 중간 수준, Sonnet보다 낫지만 "n잡", "아마존 판매" 등 여전히 모호 |

#### 상세 출력 비교

**Claude 3 Haiku** (Best)
```
- 주 1회 온라인 강의 듣기
- 퇴근 후 1시간 스킬 학습하기
- 관심분야 유튜브 채널 구독하기
- 주말에 새로운 분야 도전하기
- n잡하기
- 분야별 책 구매 및 정독하기
- 인프런/Udemy 강좌 수강하기
- 월 1회 관련 전문가 상담받기
```

**Claude 3.7 Sonnet**
```
- 주말 알바찾기
- 프리랜서 등록
- 재능 판매
- 온라인 강의
- n잡
- 웹툰 연재
- 번역 일자리
- 유튜브 채널
```

**Claude 3.5 Haiku**
```
- 블로그 시작
- 유튜브 기획
- 인스타 마케팅
- 아마존 판매
- n잡
- 프리랜서 등록
- 온라인 번역
- 웹툰 그리기
```

## 인사이트 요약

### 1. 모델 크기 ≠ 품질
- Sonnet(대형)이 Haiku(소형)보다 "실천 계획" 생성에서 오히려 품질이 낮음
- 태스크 특성에 맞는 모델 선택이 중요

### 2. 구체성 지시 필요
- 프롬프트에 "시간/횟수 포함", "10자 이내" 등 구체적 형식 지시 필요
- 모델마다 지시 따르는 정도가 다름

### 3. 비용 대비 효율
| 모델 | 대화 1회 비용 | 품질 | 추천도 |
|------|---------------|------|--------|
| Claude 3 Haiku | ~0.5원 | ⭐⭐⭐⭐⭐ | ✅ 최고 |
| Claude 3.5 Haiku | ~2원 | ⭐⭐⭐ | 보통 |
| Claude 3.7 Sonnet | ~15원 | ⭐⭐ | ❌ |
