| 영역 | 이전 | 이후 |
|---|---|---|
| 1. 헤더 배치 | 모바일·태블릿에서 `⋮`가 별도 줄. 날짜 칩은 글자만 있어 누를 수 있는지 불분명. 칩 높이 약 28px, 날짜·AI·메뉴에 초점 링 없음. 제목 입력에 이름 없음 | 날짜 칩·사용법·AI·`⋮`가 한 줄(4개 템플릿 공통 헤더). 날짜 칩에 달력 아이콘. 칩·버튼 36px 이상, `FOCUS_RING`. 제목 `플랜 제목`. 360px 만다라트만 `사용법`은 아이콘(이름 유지)·`Beta` 숨김 |
| 2. `⋮` 보조 메뉴 | 헤더에 이미 있는 `가이드` 중복. `저장` 구역이 서버 자동 저장과 헷갈림. `aria-expanded` 없음, Esc로 안 닫힘, 열어도 초점 이동 없음 | `파일로 내보내기`(JSON·이미지)·`파일에서 가져오기`(JSON)·`초기화…`만. 열면 첫 항목 초점, Esc·Tab 이탈로 닫히고 메뉴 버튼으로 복귀 |
| 3. 초기화·덮어쓰기 확인 | dialog 역할·초점 이동 없음(Tab이 배경으로), Esc 무시. 초기화 문구 "모든 데이터가 삭제"는 실제(이 플랜 칸만)와 다름. 초기화가 플랜 날짜를 오늘로 바꿈 | 공통 `ConfirmDialog`(`useModalDialog`): 이름·설명, 첫 초점 `취소`(Enter 한 번으로 실행 안 됨), Esc·배경 클릭 취소, 닫으면 메뉴 버튼으로. 바뀌는 범위·유지되는 것·되돌릴 수 없음·먼저 `JSON 저장` 안내. **초기화는 제목과 플랜 날짜를 유지**(`resetCurrent`) |

계정 이메일·저장 상태 표시, 생성·선택·주소 복원·자동 저장·최신화 보류 규칙은 바꾸지 않았다. 홈 화면·저장 안내 문구·사이드바 삭제 확인은 이번 묶음 밖이다.
