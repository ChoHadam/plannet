# 로드맵 연속 실행

2026-10-04 · 사용자 요청: 개입이 필요하지 않은 작업은 계속 진행. 구현·테스트는 Claude Opus, 범위와 결과 검토는 총괄이 담당한다.

| 순서 | 배정한 작업 | 실행 조건 |
|---|---|---|
| 현재 | 작업 복귀 검토 보완·W6 | 기존 Opus 작업 유지 |
| 다음 | 안전한 기기 간 최신화 | W6 작업 정상 종료·완료 보고 이후 |

| 이후 | 초기 로딩·입력 비용 최적화 | 앞 단계 검사 통과. 같은 조건의 개선 전후 측정 |

백그라운드 순차 실행을 연결했다. 각 단계는 새 Opus 세션에서 작업하며 보고서·검증 로그·변경 전 파일 해시를 남긴다. 다음 단계 진입에는 정상 종료, 작업 완료 보고, 통과한 검사 기록과 로그 파일, 변경 범위 검사·diff check가 필요하다. 이는 다음 작업 착수 조건이며 총괄의 최종 코드 검토 완료를 뜻하지 않는다.

**10/4 비용 개선:** [검증 정책](../verification-policy.md)을 공통 지시와 아직 시작하지 않은 UI·UX/성능 작업에 반영했다. 실행 관리자는 다음 단계 시작 직전에 지시 파일을 읽으므로 재시작 없이 적용된다. 시작된 기기 간 최신화 세션은 이전 지시로 동작한다. 그 세션을 중단·재시작해 문맥과 테스트를 반복하는 대신 현재 진행을 유지한다. 이후에는 영향별 검사 선택·통과 결과 재사용·최소 빌드·짧은 보고를 기본으로 한다.

실패·결과 누락·범위 이탈 시 후속 실행은 중단하고 총괄 확인 대상으로 기록한다. 일반 구현 문제는 총괄이 재지시하며, 실제 데이터 손실 가능성이 있는 결정이나 운영 대상·자격 증명처럼 사용자만 제공할 수 있는 사항만 사용자에게 요청한다.

실제 DB·계정·실행 서비스·공개 배포·커밋·푸시는 이 큐의 범위가 아니다. 이후 계정 내보내기·삭제 실행 취소·선택적 가져오기·CI는 별도 배정 대상으로 남는다. 홈서버 이전은 대상 환경 확인 후 진행한다.
