# 브라우저별 기록 차이와 계정 표시

2026-09-28 · 미커밋 변경.

## 확인 결과

Chrome·Arc 모두 `http://localhost:3000`의 같은 빌드에 접속했지만, 실제 Google 이메일·subject·내부 사용자 UUID가 서로 달랐다. 표시 이름은 같았다. 확인 당시 Arc 계정에는 플랜 20개, Chrome 계정에는 16개가 있었고, 각각 반복 할 일·휴일 설정 2개를 더해 서버 레코드는 22개/18개였다. 양쪽 모두 저장 완료 상태이고 임시 변경분은 없었다. 계정별 소유권 분리에 따른 조회 결과이며, 동일 계정의 데이터를 브라우저별로 다르게 저장한 현상이 아니었다.

개인 이메일과 식별값, 실제 브라우저 진단 원본은 저장소에 포함하지 않는다.

## 수정·검증

- 로그인 배지에 이름과 이메일을 함께 표시한다. 작은 화면에서도 이메일을 보여주고, 긴 주소는 말줄임 및 원문 툴팁으로 제공한다. 이름 없이 이메일을 표시 이름으로 쓰면 중복 표시하지 않는다.
- 계정 소유권·DB 저장·임시 저장 동작은 유지했다. 실제 사용자 플랜의 수정·이전·계정 병합은 수행하지 않았다. 같은 기록을 보려면 두 브라우저에서 동일한 Google 계정으로 로그인해야 한다.
- ESLint, production 빌드, 기존 로그인·계정 분리 브라우저 검사 **13개** 통과. 동일한 이름의 가상 계정 2개를 PC(1366px)·모바일(360px)에서 검증한 **4개 조합**도 통과했다. 이메일 표시·가림 없음·가로 넘침 없음·불필요한 서버 쓰기 0회를 확인했다.
- 빌드 `5Bd-pMH49Qxb8N2myhW_T`를 로컬 3000번 웹 서버에 반영했다. API·DB·로그인 세션은 유지했다. 커밋·push는 하지 않았다.
