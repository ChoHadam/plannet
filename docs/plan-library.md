# 전체 플랜 목록 (Plan Library)

사이드바는 카테고리별 **최근 만든 5개**만 보여준다. 그보다 오래된 플랜은 **전체 플랜** 보관함에서 찾아 다시 연다. 모든 카테고리(연간·월간·주간·일간)와 모든 템플릿(Mandalart·Block6·Monthly·Daily)이 한 목록에 섞여 나온다.

## 진입점

| 위치 | 동작 |
|---|---|
| 사이드바 상단 `전체 플랜 · 검색` (전체 개수 표시) | 카테고리 필터 `전체`로 연다 |
| 카테고리에 플랜이 6개 이상일 때 나오는 `더보기 · 전체 N개` | 그 카테고리 필터로 연다 |

## 보관함 기능

- **제목 검색:** 화면에 보이는 제목 기준 부분 일치. 대소문자·앞뒤 공백·연속 공백을 무시한다. 제목이 비어 있는 플랜은 `제목 없음`으로 검색된다.
- **카테고리 필터:** `전체`와 네 카테고리. 버튼마다 해당 개수를 표시한다.
- **정렬:** 최근 만든 순(기본, 사이드바와 같음) · 최근 수정 순 · 제목 순(숫자는 자연 순서).
- **결과 수·빈 상태:** `N개 플랜` / `검색 결과 N개`. 결과가 없으면 저장된 플랜 없음, 검색어와 일치 없음, 카테고리 비어 있음을 구분해 안내한다.
- **항목:** 제목, 템플릿 배지, 카테고리·날짜. 현재 선택된 플랜은 강조한다. 각 항목에서 열기·복제·삭제를 할 수 있다.

## 규칙

- **구별:** 템플릿마다 store가 따로라 id만으로는 구별할 수 없다. 목록 key·선택 비교는 `template:id`로 한다. 제목·날짜가 같은 플랜을 합치지 않는다.
- **조회 전용:** 검색·정렬·필터는 새 배열만 만든다. 플랜의 날짜·내용·`updatedAt`은 바뀌지 않는다. 플랜을 열면 해당 store의 선택 id만 바뀐다.
- **선택:** 사이드바와 같은 `selectExclusive`를 거쳐 한 템플릿만 활성화한다. 열면 보관함이 닫히고, 모바일에서는 사이드바도 닫힌다.
- **복제·삭제:** 사이드바 메뉴와 같은 흐름이다. 복제는 날짜를 고른 뒤 복제본을 선택하고 보관함을 닫는다. 삭제는 확인 모달을 거치며 보관함은 열린 채 목록만 갱신된다.
- **계정 격리:** 보관함은 현재 저장 범위의 store만 읽는다. 보관함 열림 상태는 연 시점의 저장 범위에 묶여 있어 범위가 바뀌면 이어서 보이지 않는다. 사이드바 항목 메뉴 상태도 범위가 바뀌면 초기화된다.

## 화면·접근성

- 데스크톱은 가운데 모달(최대 높이 80vh), 모바일(`md` 미만)은 전체 화면이다. 목록 영역만 스크롤된다.
- 열면 검색창에 초점이 간다. `Tab`은 모달 안에서 순환하고 `Esc`로 닫으면 연 버튼으로 초점이 돌아간다.
- 복제 날짜 선택·삭제 확인이 위에 뜨는 동안 보관함은 `inert`가 된다. 날짜 선택은 첫 버튼, 삭제 확인은 `취소` 버튼에 초점이 간다. 닫히면 보관함의 마지막 초점 위치로 돌아가고, 그 항목이 삭제됐으면 검색창으로 간다.
- 사이드바 최근 항목도 버튼이라 `Tab`·`Enter`로 선택할 수 있다. 항목 메뉴 버튼은 초점을 받으면 보인다.
