# Plannet 기획안

2026-10-11 · 기획과 시안 검토 중 · 구현 시작 전

## 관리 규칙

- 각 규칙은 해당 주제 문서에서만 수정하고 다른 문서는 링크로 연결한다. 목록에는 상태만 요약한다.
- 사용자 결정, 제안, 보류를 구분한다. 시안 승인이나 계산 예시를 구현 승인으로 간주하지 않는다.
- 후보가 채택되면 해당 주제의 본문으로 옮기고 후보 문서에는 채택 결과를 링크한다.
- 최신 결정과 다른 내용은 [보관 기록](archive/README.md)에서만 유지한다. 보관본은 현재 규칙의 근거로 사용하지 않는다.
- 이미지와 생성 프롬프트는 [기존 에셋 폴더](../assets/character-concepts/)를 공통으로 참조한다. 파일을 중복 복사하지 않는다.
- 기존 두 통합 문서 주소는 안내 페이지로 유지한다. 앞으로 이 폴더의 주제별 문서를 갱신한다.
