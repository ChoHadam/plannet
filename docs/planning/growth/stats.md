# 능력치와 회고

2026-10-11 · 최신 사용자 결정 반영 · [기획 목록](../README.md)

사용자가 키우고 싶은 능력치를 직접 관리한다. 별도의 분야 분류를 두지 않는다. 능력치는 실제 건강·지능·인격의 평가가 아닌 게임 안의 활동 기록이다.

## 결정된 방향

| 항목 | 규칙 |
|---|---|
| 기본 구성 | 체력·지혜·평온·재주로 시작 |
| 수정 | 이름·아이콘 자유 수정, 기존 수치·기록 유지 |
| 추가 | 새 능력치 추가 가능 |
| 실천 연결 | 할 일 하나에 능력치 하나 연결 |
| 증가량 | 연결된 할 일의 완료당 해당 능력치 +1. 난이도·시간 배율 없음 |
| 주간 감소 | 매주 −1 옵션, 기본 ON, 최저 0 |
| 감소 OFF | 설정이 꺼진 동안 주간 감소하지 않음 |
| 보호되는 성취 | 코인·집·완료 공정·누적 실천 기록은 감소하지 않음 |

이름이 바뀌어도 동일 능력치의 기록을 이어간다. 의미 변경을 판별하거나 다른 분야인지 묻는 추가 절차는 두지 않는다. 기본 아이콘 후보는 번개·책·초승달·반짝임이며 자유 수정할 수 있다.

## 실천 연결과 템플릿 적용

**사용자 확정: 할 일 하나에 능력치 하나, 완료당 +1.** AI 자동 분류·여러 능력치 분배는 초기 규칙에 넣지 않는다. 건축 재화의 1코인과 독립적인 규칙이다.

다음은 이 규칙의 운영 제안이며 세부 처리는 구현 전에 확정한다.

- 작성·편집 중 능력치를 선택한다. 미선택 항목은 일반 할 일로 저장·완료하고 능력치는 올리지 않는 안을 추천한다.
- 반복 할 일은 연결을 유지하고 서로 다른 실행 회차마다 +1을 지급한다. 같은 실행의 재전송·취소 후 재체크로 중복 적립하지 않는다.
- 완료 취소는 해당 실행의 +1을 정정하고 재완료 시 복원하는 안이다. 주간 감소가 이미 반영된 뒤의 정산·최저 0 처리는 별도 설계한다.
- 완료 후 능력치 연결 변경은 완료 취소 → 수정 → 재완료 순서를 추천한다. 과거 기록까지 일괄 재분류하지 않는다.

일일 계획 전용 기능일 필요는 없다. 기간·템플릿 이름보다 실제 실행 건인지가 기준이다. 아래는 현행 완료 필드를 확인한 적용 제안이며, 모든 템플릿 동시 구현을 확정한 표는 아니다.

| 템플릿 | 연결할 대상 제안 | 주의점 |
|---|---|---|
| Daily | 개별 할 일 | 실행 회차별 완료 기록 필요 |
| Block6 | 블록 안의 개별 할 일 | Daily를 거치지 않고 독립적으로 적용 가능 |
| Mandalart | 구체적인 실천 계획 셀 | 핵심·하위 목표의 완료 전파를 별도 실천으로 중복 계산하지 않음 |
| Monthly | 구체적인 실행으로 사용하는 항목 | 월간 목표 요약의 완료와 하위 실행을 중복 보상하지 않음 |

현재 네 템플릿에 완료 상태는 있지만 공통 실행 기록·능력치 연결·보상 기능이 이미 구현된 것은 아니다. 특히 하나의 상위 목표에서 반복되는 여러 실행을 출처 ID만으로 같은 실행으로 합치면 안 된다. 반대로 같은 실행을 다른 템플릿으로 가져온 경우에는 +1을 한 번만 반영해야 한다.

단순한 첫 구현 범위로는 명확한 할 일 구조가 있는 Daily·Block6부터 적용하는 안을 추천한다. 적용 순서는 미확정이며, 어느 템플릿도 다른 템플릿 사용을 필수로 요구하지 않는다.

## 제안과 미결정

- 주간 감소 토글은 능력치별이 아닌 전체 공통 하나를 제안했다. 적용 범위는 아직 명시적으로 확정하지 않았다.
- 1:1 연결과 완료당 +1은 확정했다. 미선택 항목 처리·취소 정산·첫 적용 템플릿 범위는 위 제안을 기준으로 검토한다.
- 삭제는 신중하게 다루려는 사용자 방향이 있다. 보관 기능은 제안이며 삭제·보관의 구체적인 정책과 추가 개수 상한은 미정이다.
- 감소 기준 요일·시간대, 미접속 기간 계산, 새 능력치의 첫 감소, 토글 변경 시 소급 여부는 구현 전에 정한다.

## 월간과 연간 회고

현재 수치와 누적 실천 기록을 분리한다. 회고는 감소 후 잔액이 아닌 실제 실천·증가 기록으로 계산해 어떤 능력치에 집중했는지 보여준다. 실천 증가와 시간 경과 감소를 구분해 기록한다. 이름 변경 후 과거 차트의 이름 표시 방식은 미정이다.

주간 −1은 쉬었던 능력치가 서서히 낮아지는 효과다. 주간 +20이면 순증가는 +19이므로 급성장 억제 효과를 과장하지 않는다. 집의 후퇴 금지와 현재 능력치의 선택적 감소는 별개 규칙이다.
